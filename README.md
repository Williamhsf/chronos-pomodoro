# Chronos Pomodoro ⏱️

O Chronos Pomodoro é uma aplicação web desenvolvida com React para gerenciamento de tempo e tarefas utilizando a técnica Pomodoro. O projeto faz parte dos meus estudos em desenvolvimento front-end, acompanhando um curso prático com o objetivo de aprender a construir uma aplicação do zero até sua publicação na internet.

## 🎯 Objetivo do projeto

Praticar os principais conceitos do React por meio da construção de uma Single Page Application (SPA), explorando componentes, gerenciamento de estado, temporizadores, armazenamento local e navegação entre telas.

## ✨ Funcionalidades

- Temporizador regressivo: gerenciamento dos ciclos de foco e descanso.

- Gerenciamento de tarefas: definição da atividade que será realizada durante o ciclo.

- Configurações personalizadas: ajuste dos tempos de foco, descanso curto e descanso longo.

- Histórico de atividades: registro das sessões, com seus horários e status, como concluída ou interrompida.

- Armazenamento local: utilização do Local Storage para preservar configurações, tema e histórico no navegador.

- Tema claro e escuro: alternância entre os modos de exibição.

- Notificações: avisos para informar o término de um ciclo.

- Execução em segundo plano: utilização de Web Workers para auxiliar no gerenciamento do temporizador.

- Validação de formulários: verificação dos dados informados pelo usuário.

- Ordenação do histórico: organização dos registros diretamente na interface.

- Navegação entre telas: troca de componentes sem recarregar a página, além de páginas informativas sobre a técnica Pomodoro.

## 💾 Como executar o projeto

Certifique-se de ter o Node.js instalado.

Clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Acesse a pasta do projeto:

```bash
cd chronos-pomodoro
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento, caso o projeto utilize esse script:

```bash
npm run dev
```

Acesse o endereço local informado pelo terminal.

Os comandos podem variar de acordo com a estrutura e a configuração do projeto.
